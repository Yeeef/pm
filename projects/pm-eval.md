## Goal

> Why do we do it? What is it? What outcome do we expect?

Find public, online benchmarks or evals of long-horizon agent work, and use them to show, with numbers, whether an agent that runs with pm does better on long-horizon tasks than the same agent without it. The owner's words: "find some online bench / eval that we can use pm to prove that pm helps long horizon task performance". The project ends with a result on at least one recognised benchmark, run with and without pm under otherwise equal settings, whatever the result shows.
